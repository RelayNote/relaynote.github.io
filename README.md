# 继电保护全过程调试工具

面向光储电站、变电站、水电站二次调试的专业在线工具集。

## 功能模块

1. **全站保护配置** —— 基于主接线形式的保护配置方案与各元件保护原理知识讲解
2. **调试手册与计算工具** —— 母线/主变/线路/备自投/稳控/故障录波/PMU/SPDC 等调试指导，CT极性核查、一次通流、PT二次通压、跳闸矩阵，带负荷测试计算工具
3. **保护配合与本体调试** —— 电气五防/联闭锁逻辑、主变本体、SVG本体、接地变本体调试指导
4. **送电二次核相助手** —— 核相判断 + 向量图
5. **报告出具工具** —— 一键生成调试报告
6. **小工具集** —— GBK↔HEX 互转（保护报文解析）、定值一次/二次换算、动作时间误差校验、线路阻抗计算

## 本地运行

由于使用 ES Module 动态加载 HTML 片段，**不能直接双击打开 index.html**，需要通过 HTTP 服务访问：

```bash
# 方法一：Python
python3 -m http.server 8000

# 方法二：Node
npx serve .

# 浏览器打开 http://localhost:8000
```

## 部署到 GitHub Pages

> ⚠️ 已修复子路径部署问题：自动兼容 `https://用户名.github.io/仓库名/` 这种子路径，无需手动改路径。

1. 把仓库根目录下的全部文件（`index.html`、`css/`、`js/`、`pages/`、`data/`、`.nojekyll`、`README.md`）推送到 GitHub 仓库。
   - **注意**：`index.html` 必须在仓库根目录，不要多套一层文件夹。
2. 进入仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main` + `/ (root)`，保存。
3. 等 1–2 分钟构建完成，访问 `https://你的用户名.github.io/你的仓库名/`。

### 常见问题

- **页面空白 / 侧边栏点击无反应**：
  - 确认 `index.html` 在仓库**根目录**（不是子文件夹里）。
  - 确认 `.nojekyll` 文件已上传（文件名就是 `.nojekyll`，无扩展名）。
  - 打开浏览器 F12 控制台看具体报错；本版已加入错误提示浮层，会自动显示运行异常。
  - GitHub Pages 构建需要 1–2 分钟，新推送后等一会再刷新（可 Ctrl+F5 强刷）。
- **样式错乱 / 资源 404**：检查是否存在多余的目录层级；CSS/JS/HTML 必须按压缩包里的相对位置放置。

## 目录结构

```
.
├── index.html         # 入口文件（精简骨架，自动适配子路径）
├── css/               # 样式（base / layout / components）
├── js/                # 逻辑模块（按页面拆分）
├── pages/             # 各页面 HTML 片段（动态加载）
├── data/              # 专业数据（标准库、GBK 编码映射）
└── assets/            # 预留静态资源目录
```
